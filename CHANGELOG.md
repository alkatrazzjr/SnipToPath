# Changelog

## Unreleased

- Исправлена прокрутка и обрезание языковых настроек при обычном размере окна: тема и язык теперь расположены в общей нижней строке.
- Поля ввода папки и задержки получили скругления и единый стиль с подсветкой фокуса.
- Добавлена автоматическая проверка реального размера области настроек на Windows в русском и английском интерфейсе.


- В трей добавлена кнопка «Открыть папку PNG»: открывает выбранную папку в Проводнике на обоих языках интерфейса.

- Автоматическое определение языка по языку интерфейса Windows: русский для ru-*, английский в остальных случаях.
- Ручной выбор языка (автоматически/русский/английский) в настройках, переключение без перезапуска.
- Переведены интерфейс трея, окно настроек и сообщения об ошибках; добавлен README на английском.

- Меню трея уменьшено до переключателя обработки изображений, настроек и выхода. Расположение рассчитывается в координатах системного окна и ограничивается рабочей областью выбранного монитора.
- В настройках появился редактируемый путь к папке PNG и современный выбор папки через Проводник.
- Задержка удаления задаётся в секундах от 1 до 604800. Старые значения в минутах переносятся автоматически.
- README сокращён и переписан под актуальный интерфейс.

- Установка больше не использует `File.Replace`: новая версия сначала сохраняется отдельно, старая временно переносится в резервную копию и восстанавливается при ошибке.
- Установщик обходит кэш при скачивании с GitHub и показывает SHA256 полученного файла.
- Добавлена полная проверка установки и обновления в Windows PowerShell 5.1, а не только тест вспомогательной функции.

- Исправлена установка поверх предыдущей версии: Windows PowerShell 5.1 больше не падает на `File.Replace` из-за отсутствующего пути резервной копии.
- Добавлены тесты первой установки, обновления и восстановления после неудачного копирования.

- Не перезаписывает новое содержимое буфера, если оно изменилось во время сохранения PNG.
- Безопасное обновление через временный файл с заменой установленного скрипта.
- Очистка удаляет только файлы с именами, созданными SnipToPath, даже при выборе общей папки.
- Регрессионные тесты работы с буфером и удаления PNG на Windows runner.

- Окно настроек переработано в две колонки: компактная компоновка, нормальные цвета заголовков, статус паузы, быстрый доступ к папке.
- Настраиваемая задержка удаления PNG (5/15/30/60 минут), синхронизация с меню трея.
- Исправлен порядок каналов системного акцентного цвета и состояние кнопок.

- Новое компактное меню трея на WPF вместо стандартного WinForms ContextMenuStrip.
- Новая иконка приложения и исходники иконки в assets; обновлена документация.
- Настройки, быстрые действия и меню используют общую тему Windows.

- По умолчанию старый временный PNG удаляется через 5 минут после следующего копирования в буфер.
- Очистку при смене буфера можно отключить в настройках и меню трея.
- README переписан и дополнен описанием срока хранения скриншотов.


## 0.1.0 — Initial public release (planned)

- Clipboard image → unique PNG → plain-text file path.
- WPF settings window with Windows light/dark mode and accent color.
- Tray menu: settings, pause, startup, theme, open folder, cleanup, exit.
- User-level installation and Windows Start Menu shortcut.
- Optional cleanup of temporary screenshots on application start.
- No external runtime dependencies.
