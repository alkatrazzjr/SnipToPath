# SnipToPath

Когда работаешь с Codex CLI или Claude Code в терминале, постоянно сохранять скриншоты вручную неудобно. SnipToPath делает это сам: берёт изображение из буфера обмена, сохраняет PNG и копирует вместо картинки путь к файлу.

Скопировал картинку → вернулся в консоль → вставил путь. Всё.

Работает на Windows 10/11, использует встроенный Windows PowerShell и системные библиотеки. Дополнительные программы не нужны.

## Установка

Открой PowerShell и вставь:

```powershell
irm https://raw.githubusercontent.com/alkatrazzjr/SnipToPath/main/install.ps1 | iex
```

Приложение появится в поиске «Пуск» и в трее рядом с часами. Права администратора не нужны. Обновляется той же командой; настройки сохраняются.

## Использование

Сделай скрин через `Win + Shift + S` или `Print Screen` либо просто скопируй изображение из браузера, мессенджера или другого приложения. Если изображение оказалось в буфере, SnipToPath сохранит его в PNG.

В Codex CLI (`codex`) или Claude Code CLI (`claude`) нажми `Ctrl + V` и добавь свой запрос. Если терминал перехватывает это сочетание, попробуй `Ctrl + Shift + V`.

Вставляется **путь к файлу, а не само изображение**. Агент должен иметь возможность открыть этот PNG на компьютере. В WSL Windows-путь может потребоваться преобразовать в `/mnt/c/...`.

## Трей и настройки

Правый клик по значку открывает компактное меню. Там можно поставить обработку на паузу, включить или выключить автозапуск и очистку, открыть папку с файлами или выйти. Двойной клик открывает настройки: папка сохранения, задержка удаления, кавычки вокруг пути и тема оформления. Светлая и тёмная темы следуют настройке Windows, если не выбрать другую вручную.

PNG по умолчанию лежат в `%TEMP%\SnipToPath`. Чтобы они не копились, программа:

- после следующего копирования ставит предыдущий PNG на удаление (по умолчанию через **5 минут**);
- удаляет оставшиеся временные PNG при следующем запуске;
- позволяет очистить папку вручную из трея.

Эти функции включены по умолчанию, но их можно отключить. Пятиминутная задержка нужна, чтобы не удалить файл, пока агент ещё его открывает. Задержку можно выбрать в настройках: 5, 15, 30 или 60 минут. Если агенту нужен файл дольше, увеличь задержку или отключи автоудаление. Программа не изменяет обычный скопированный текст и ничего не отправляет в интернет. При этом она не умеет надёжно определять, из какого приложения пришла картинка: снимки экрана и скопированные изображения обрабатываются одинаково.

## Удаление

В PowerShell:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\SnipToPath\SnipToPath.ps1" -Uninstall
```

Удалятся приложение, его настройки, ярлыки и временные PNG.
